# 🎬 Netflix Clone (HTML + CSS)

A fully responsive **Netflix Homepage Clone** created using **HTML5 & CSS3 only**.  
This project recreates Netflix’s modern UI including hero section, trending cards, FAQ accordion design, and footer layout.

---


---

## ⭐ Features  
### 🔥 Hero Section  
- Background banner  
- Netflix logo  
- Language switcher  
- Sign-in button  
- Email subscription box  

### 🎞 Trending Section  
- Horizontal movie cards  
- Ranking numbers (1, 2, 3, 4)  
- Images with hover-style design  

### 🧩 Why Join Netflix Section  
- 4 custom info boxes  
- Icons & images  
- Proper layout & spacing  

### ❓ FAQ Section  
- 6 FAQ blocks  
- Netflix-style accordion look  
- Plus icon on right side  

### 📬 Footer Section  
- Multi-column footer links  
- Netflix India label  
- reCAPTCHA notice  

---

## 🛠 Technologies Used  
- **HTML5**  
- **CSS3**  
- Flexbox  
- Positioning  
- Absolute elements for ranks  
- Gradient dividers
